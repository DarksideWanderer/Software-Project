我负责实现的是 AI-service 中的 NLU 自然语言理解部分，负责把用户的自然语言指令解析为后端可执行的动作计划。考虑的想法是采用规则识别 + LLM 大语言模型兜底的方式，首先根据设备名称，类型关键词，或者房间 + 类型等方式进行匹配，然后解析对应的操作和参数等，最后会返回一个 JSON 格式的解析字段，包括是否成功理解的 `understood`，以及回答 `reply` 还有对应的操作 `action`。如果不能匹配成功则调用 deepseek API 进行处理。

具体实现的过程中，我采用了 AI 辅助编程实现，为了保证 AI 帮我写的代码符合我的预期，我采用了测试引导的方式进行实现，即先对照应用层给出的需求，生成对应的测试代码，经过人工审核之后，再让 AI 实现核心代码，以通过所有测试用例为目标进行生成，这样可以让 AI 更清晰要实现的目标以及各种边界上的问题，同时也可以让其在单次实现中尽可能做到面面俱到。

这次大作业让我认识到，AI 开发最大的问题是有上下文窗口限制以及目标明确性的问题，个人认为一种好的实践方式是采用先生成文档+测试，再生成核心代码，可以让 AI 更加清晰地进行实现，也避免了很多细节上的问题，最终生成的代码也更好。
