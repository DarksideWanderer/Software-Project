# 陈浩贤课程实践心得

我是本组组长，同时负责后端方向的开发与协调工作。本次项目中，我主要参与了 `backend-core` 的接口设计、家庭与设备数据结构整理、设备绑定与状态同步、场景执行、AI 服务接入以及整体联调工作。后端需要同时连接前端页面、AI 服务和 C++ 家电模拟器，因此我在开发过程中重点关注接口稳定性、数据流是否清晰，以及异常情况下前端能否得到明确反馈。

作为组长，我更多体会到项目推进不只是完成自己负责的代码，还要让不同方向的工作能够接起来。前端需要明确接口格式，AI 需要知道设备和动作如何表达，模拟器需要和主后端保持注册、控制和状态返回的一致性。为此，我在开发过程中持续整理模块边界、推进联调问题修复，并根据项目进度调整文档和任务安排，尽量保证每个成员的工作都能落到最终系统中。

这次课程实践让我对软件工程中的协作有了更直接的认识。一个功能能跑通，往往不是某一段代码单独完成的结果，而是需求分析、接口约定、实现、测试和文档共同配合的结果。作为组长，我也认识到及时沟通、明确责任和控制范围的重要性，后续如果继续完善这个项目，我会更早地建立统一的数据契约和验收标准，减少后期联调中的反复修改。
