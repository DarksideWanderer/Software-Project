# 覃锐麟课程实践心得

我是本组后端方向成员，主要参与了家电模拟后端和主后端设备通信相关工作。本次项目中，我重点负责 `device-simulator` 的 C++ 设备进程设计与实现，以及它和 `backend-core` 中 DeviceHub 的联调。每个模拟家电作为独立进程启动，通过 TCP 向主后端注册设备 ID、设备类型、可用命令和状态字段，再由后端统一下发控制命令，这让我对设备发现、状态同步和接口约定有了更直观的理解。

在实现过程中，我也参与了多类型设备的扩展，包括空调、灯、电视以及更多通用家电类型。相比只写一个固定设备，通用设备和适配器的设计更考验抽象边界：既要让不同家电保留自己的状态和控制方式，又要让后端能用统一接口进行发现、绑定、控制和查询。这问题让我意识到前后端要密切沟通,协调好接口规范,这也让我真正意识到软件工程开发中团队合作和沟通的重要性。

这次课程实践也让我体会到，后端开发并不只是写接口，还包括通信协议、运行环境、测试验证和文档说明。特别是和前端、AI 服务一起联调时，任何一个字段不统一都会影响整体功能。通过这次项目，我对模块化设计、进程通信和团队协作有了一次实际的体验和深刻的认识，也更加理解了软件工程开发规范的必要性和重要性。
