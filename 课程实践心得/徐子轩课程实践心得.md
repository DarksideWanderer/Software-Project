# 徐子轩课程实践心得

我是本组前端开发成员，主要负责智能家居 Web 控制台。实践中，我先完成设备总览、设备卡片、详情抽屉、一键场景、文字/语音助手和响应式布局等可交互原型；随后根据页面流程整理前端 API 需求，向后端和 AI 模块明确设备控制、场景执行、助手消息、语音上传等接口契约。联调阶段，我把页面接入 backend-core、DeviceHub 和 ai-service，并补充离线、加载、错误提示与助手 TTS 播放等展示细节。

这次经历让我体会到，前端并不是单纯“画页面”，而是要把用户操作、接口设计、异常反馈和演示稳定性串成完整闭环。只有先确认需求和交互，再与后端、AI、设备模拟模块持续对齐，系统才能真正可用。多轮实现和修正也让我更理解软件工程中的分工协作、接口约定和测试验证的重要性。
