# Smart Home Mobile App

## Introduction
Multi-platform mobile application for user interaction, real-time device control, and status monitoring.

## Tech Stack
- **Framework**: Flutter
- **Language**: Dart
- **State Management**: Riverpod / Bloc
- **Messaging**: MQTT Client

## Directory Structure
- `lib/models/`: Data models
- `lib/providers/`: State management
- `lib/screens/`: UI Views
- `lib/widgets/`: Reusable components
- `test/`: Flutter widget and unit tests
