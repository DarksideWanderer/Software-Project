# 栖居全屋智能 Web Demo

纯前端的全屋智能中控台视觉 Demo，不依赖后端服务或第三方运行时依赖。

## 功能

- 总仪表盘展示空调、两盏灯、电视、冰箱与风扇状态
- 设备卡片快速开关与详情控制面板
- 回家、观影、睡眠、离家四种场景联动
- 文本智能指令解析与可视化执行反馈
- 模拟语音录音、识别和设备控制流程
- 桌面端与移动端响应式布局

## 本地运行

在当前目录执行：

```bash
python3 -m http.server 4173
```

然后访问 <http://localhost:4173>。

这是一个交互原型，所有设备状态仅保存在当前页面内，刷新后会恢复默认状态。
