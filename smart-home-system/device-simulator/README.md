# Smart Home Device Simulator

## Introduction
Simulates smart home hardware devices (Lights, AC, Sensors) and common protocols to enable development without physical hardware.

## Tech Stack
- **Language**: C++ 20
- **Build System**: CMake
- **Messaging**: Mosquitto (MQTT Library)
- **Testing**: Google Test (GTest)

## Directory Structure
- `include/`: Header files
- `src/core/`: Protocol abstraction
- `src/devices/`: Virtual device implementations
- `tests/`: GTest cases
- `scripts/`: Simulation control scripts
