# System Deployment & Infrastructure

## Overview
Contains Docker configurations, CI/CD pipelines, and environment setup scripts for the entire ecosystem.

## Directory Structure
- `docker/`: Dockerfiles and docker-compose.yml
- `k8s/`: Kubernetes manifests
- `scripts/`: Tooling for one-click deployment
- `env/`: Environment variables templates
